How does DocuMind answer questions from a PDF?

When you upload a PDF, PyMuPDF extracts text from each page and splits it into 500-character passages with a 50-character overlap so sentences are never cut off mid-thought. Each passage is converted into a 384-dimensional vector using HuggingFace's all-MiniLM-L6-v2 model locally and stored in ChromaDB for instant semantic search without extra API costs.
